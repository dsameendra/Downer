# Security Policy

## Supported versions

Only the latest release of Downer receives fixes.

| Version | Supported |
|---|---|
| 2.0.x | Yes |
| older | No |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**. Include what you found, how to reproduce it, and which version of Downer you used.

You can expect a first reply within a week. Downer runs `yt-dlp` and `ffmpeg` on your machine with the links you give it, so reports about how those tools are launched are especially welcome.
